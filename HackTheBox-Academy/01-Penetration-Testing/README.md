## Overview

This section documents penetration-testing methodology and foundational offensive-security skills developed through Hack The Box Academy training.

The training focused on understanding the penetration-testing process, performing reconnaissance and information gathering, identifying attack surfaces, conducting enumeration, and assessing vulnerabilities within authorized laboratory environments.

The objective of this section is to demonstrate practical knowledge of penetration-testing workflows and security assessment techniques relevant to cybersecurity analyst, security engineering, vulnerability management, and offensive-security roles.
