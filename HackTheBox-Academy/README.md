## Overview

This section documents my completed **Hack The Box Academy** training and hands-on cybersecurity modules.

The training covers the penetration-testing lifecycle from reconnaissance and enumeration through vulnerability assessment, exploitation, privilege escalation, Active Directory attack techniques, and network pivoting.

The modules complement my graduate cybersecurity coursework, TryHackMe training, Network Defense Essentials training, and independent technical projects.
