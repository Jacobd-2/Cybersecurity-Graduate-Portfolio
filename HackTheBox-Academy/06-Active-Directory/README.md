## Overview

This section documents Active Directory security and Windows domain-environment skills developed through Hack The Box Academy hands-on training.

The training focused on understanding Active Directory environments, enumerating domain information, analyzing users and groups, identifying security weaknesses, and understanding how identity and access relationships can affect the security of a Windows domain.

These skills are applicable to both offensive and defensive security activities, including penetration testing, vulnerability assessment, identity and access management, security operations, and incident response.

Active Directory security knowledge is valuable for both offensive and defensive cybersecurity.

* Enumerating Windows domain environments
