## Overview

This section documents web application security skills developed through Hack The Box Academy hands-on training.

The training focused on identifying and analyzing common web application vulnerabilities, understanding how insecure input handling can expose applications to attack, and using security-testing tools to evaluate application behavior within authorized laboratory environments.

The training provided practical exposure to web reconnaissance, proxy-based testing, fuzzing, injection vulnerabilities, file handling weaknesses, and application attack techniques.
