## Overview

This section documents network enumeration and reconnaissance skills developed through Hack The Box Academy training.

The training focused on identifying hosts, discovering open ports, enumerating network services, analyzing exposed attack surfaces, and collecting information that can support subsequent vulnerability assessment and security testing.

These skills are foundational to penetration testing and are also applicable to defensive security roles involving network monitoring, vulnerability management, threat detection, and security engineering.

## Completed Training

The following Hack The Box Academy modules contributed to this training area:

* **Network Enumeration with Nmap**
* **Footprinting**
* **Information Gathering - Web Edition**

These modules developed practical knowledge of reconnaissance, network discovery, service enumeration, and information collection within authorized training environments.

## Key Skills Developed

### Network Discovery

* Identifying accessible hosts and network targets
* Discovering exposed network services
* Performing port scanning
* Understanding TCP and UDP service exposure
* Interpreting network scan results
* Mapping potential attack surfaces

### Service Enumeration

* Identifying services running on discovered ports
* Determining service versions
* Collecting information about exposed applications
* Using enumeration results to identify potential vulnerabilities
* Prioritizing services for further security assessment

### Nmap

Practical training included the use of **Nmap** for network reconnaissance and enumeration.

Skills developed include:

* Host discovery
* Port scanning
* Service and version detection
* Scan-result analysis
* Network mapping
* Identifying exposed services
* Using enumeration results to guide subsequent security testing

## Security Applications

Network enumeration knowledge can support both offensive and defensive security activities.

### Offensive Security

* Identifying exposed services
* Mapping an organization's attack surface
* Discovering potential entry points
* Gathering information for vulnerability assessment
* Supporting penetration-testing workflows

### Defensive Security

* Identifying unnecessary exposed services
* Supporting vulnerability management
* Reviewing network attack surfaces
* Improving network segmentation
* Detecting unexpected services or ports
* Supporting security monitoring and incident investigations
