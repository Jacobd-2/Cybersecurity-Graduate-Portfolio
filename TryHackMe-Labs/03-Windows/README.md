## Overview

This section documents Windows-focused cybersecurity training completed through **TryHackMe**.

The Windows Fundamentals rooms provided hands-on exposure to Windows operating system concepts, system configuration, administrative tools, security settings, and foundational Windows security practices.

Windows knowledge is especially important in cybersecurity because Windows environments are widely deployed across enterprise organizations and are common targets for security incidents, credential attacks, malware, and unauthorized access.
