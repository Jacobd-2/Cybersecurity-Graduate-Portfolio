## Overview

This section documents security-focused foundational training completed through **TryHackMe**.

The completed rooms introduce core cybersecurity concepts across vulnerability identification, offensive security, defensive security, physical security, and security awareness.

These exercises helped develop a broader understanding of how security threats affect organizations and how technical, administrative, physical, and human-focused controls can be used to reduce risk.

## 01 — Vulnerabilities 101

**Focus:** Vulnerability Management Fundamentals

Developed foundational knowledge of cybersecurity vulnerabilities and their potential impact on systems and organizations.

### Concepts Covered

* Security vulnerabilities
* Common weaknesses
* Vulnerability identification
* Risk concepts
* Security impact
* Vulnerability management fundamentals

### Security Relevance

Understanding vulnerabilities is essential for identifying weaknesses before they can be exploited and for prioritizing security improvements based on organizational risk.

## 02 — Offensive Security Intro

**Focus:** Offensive Security Fundamentals

Explored foundational concepts associated with offensive security and authorized security testing.

### Concepts Covered

* Offensive security
* Attack concepts
* Security testing
* Attacker techniques
* Security assessment fundamentals

### Security Relevance

Knowledge of offensive security helps defenders understand how attackers identify and exploit weaknesses, allowing organizations to improve preventative and detective security controls.

All offensive-security activities were performed within authorized TryHackMe training environments.

## 03 — Defensive Security Intro

**Focus:** Defensive Security & Blue-Team Concepts

Developed foundational knowledge of defensive cybersecurity and the responsibilities involved in protecting systems and networks.

### Concepts Covered

* Defensive security
* Blue-team concepts
* Threat detection
* Security monitoring
* Defensive controls
* Security operations fundamentals

### Security Relevance

Defensive security concepts directly support security operations, threat detection, incident response, and continuous monitoring.

---

## 04 — Physical Security Intro

**Focus:** Physical Security Controls

Explored the role of physical security in protecting organizational systems, facilities, equipment, and information.

### Concepts Covered

* Physical security
* Physical threats
* Security controls
* Facility protection
* Physical access considerations

### Security Relevance

Cybersecurity extends beyond software and networks. Physical access to systems and facilities can affect confidentiality, integrity, and availability and should therefore be considered as part of an organization's overall security strategy.

---

## 05 — Security Awareness Intro

**Focus:** Human Factors & Security Awareness

Explored the importance of security awareness and the role employees play in protecting organizational systems and information.

### Concepts Covered

* Security awareness
* Human factors
* Social engineering
* Security behavior
* Employee security responsibilities
* Security culture

### Security Relevance

Human behavior is an important component of organizational security. Security awareness programs can help employees recognize threats and follow appropriate security practices.
