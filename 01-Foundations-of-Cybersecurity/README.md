## Course Overview

This course developed foundational knowledge in cybersecurity operations, including **threat analysis, vulnerability assessment, risk management, security controls, network defense, incident response, security monitoring, and critical infrastructure protection**.

The portfolio projects and hands-on labs below demonstrate the application of these concepts in controlled academic environments.


---

## Portfolio Highlights

* Analyzed cybersecurity risks affecting **critical infrastructure and power-grid operations**
* Applied the **Cyber Kill Chain** to analyze adversary activity
* Performed **risk assessments and security gap analysis**
* Applied **NIST SP 800-30** and **OCTAVE Allegro** risk-management methodologies
* Analyzed malware and security-breach scenarios
* Applied **Windows security hardening and authentication auditing**
* Conducted **packet capture and network traffic analysis**
* Applied authentication, access control, encryption, and security-monitoring concepts
* Evaluated attack vectors and defensive security controls
* Developed security recommendations focused on **defense in depth and cyber resilience**

* Applied the **Cyber Kill Chain** to adversary activity
