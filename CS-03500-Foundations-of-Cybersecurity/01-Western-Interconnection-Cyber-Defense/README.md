# Western Interconnection Cyber Defense

| **Project** | **Western Interconnection Cyber Defense**                                                                        |
| :---------- | :--------------------------------------------------------------------------------------------------------------- |
| **Focus**   | Critical Infrastructure Security • Threat Intelligence • Cyber Kill Chain • Defense in Depth • Mission Assurance |

## Project Overview

This project simulated a cybersecurity engagement focused on defending the **Western Interconnection power grid** against a sophisticated foreign government-sponsored cyber threat.

The engagement was developed from the perspective of a security analyst working for a simulated U.S. Department of Defense contractor responsible for developing a defensive strategy for critical infrastructure.

The project examined cybersecurity risks across **supply chain security, threat intelligence, adversary analysis, Cyber Kill Chain analysis, defense in depth, and mission assurance**.

---

# Project Objectives

* Identify cybersecurity risks affecting critical infrastructure supply chains
* Analyze potential cyber threats targeting power-grid environments
* Develop an adversary profile and assess attacker capabilities
* Apply the **Cyber Kill Chain** to a simulated malware scenario
* Evaluate defense-in-depth security controls
* Examine **Industrial Control System (ICS)** and SCADA security
* Evaluate mission-assurance requirements and operational procedures
* Develop recommendations for improving cyber resilience

# Portfolio Context

This project was completed in a **controlled academic environment** to demonstrate the application of cybersecurity concepts to a simulated critical infrastructure environment.

The project demonstrates an end-to-end defensive approach:

**Supply Chain Security → Threat Analysis → Cyber Kill Chain → Defense in Depth → Mission Assurance**

The work demonstrates skills in **critical infrastructure security, threat analysis, network defense, ICS security, security controls, incident response, and cyber resilience**.

No unauthorized systems or production environments were targeted, accessed, or tested as part of this project.

## Disclaimer

This work was completed as an academic cybersecurity simulation. No real-world critical infrastructure systems were targeted, accessed, or tested.
