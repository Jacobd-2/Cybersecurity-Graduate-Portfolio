## Lab Overview

This hands-on lab focused on deploying an **Endpoint Detection and Response (EDR)** solution to endpoints.

The lab was completed using *Cyberwarfare: Information Operations in a Connected World, Second Edition* and provided practical experience deploying an EDR solution and examining endpoint security monitoring capabilities.

The exercise demonstrated how EDR technologies provide security teams with visibility into endpoint activity and support the detection, investigation, and response to potential security threats.

**Time on Task:** 12 hours, 3 minutes
**Completion:** 100%

---

# Lab Objectives

The primary objectives of this lab were to:

1. Understand the purpose of Endpoint Detection and Response solutions.
2. Deploy an EDR solution to endpoints.
3. Configure an EDR agent on a workstation.
4. Examine endpoint security monitoring capabilities.
5. Review endpoint security information through an EDR dashboard.
6. Understand how EDR supports threat detection and investigation.
7. Apply endpoint-defense concepts within a controlled environment.
8. Document technical evidence from the EDR deployment.

# 1. Deploy an EDR Solution to Endpoints

The hands-on portion of the lab focused on **deploying an Endpoint Detection and Response solution to endpoints**.

EDR platforms provide security teams with centralized visibility into endpoint activity and can support security monitoring, threat detection, investigation, and response.

### Security Concept

Endpoint Detection and Response solutions are designed to monitor endpoint activity and provide security teams with information that can be used to identify and investigate potentially malicious behavior.

### Security Objective

The exercise demonstrated the deployment of an EDR solution to an endpoint and provided hands-on experience working with endpoint security monitoring capabilities.

# 4. Endpoint Detection & Monitoring

EDR technologies provide security teams with visibility into endpoint activity.

### Endpoint Monitoring Process

```text
Endpoint Activity
      ↓
EDR Agent
      ↓
Telemetry Collection
      ↓
Security Monitoring
      ↓
Threat Detection
      ↓
Investigation
      ↓
Response
```

This monitoring capability allows security teams to investigate endpoint activity and identify events that may require additional analysis.

---

# 5. Endpoint Detection & Response

EDR extends traditional endpoint protection by providing capabilities for monitoring, detection, investigation, and response.

### Core EDR Functions

* Endpoint monitoring
* Security telemetry collection
* Threat detection
* Endpoint investigation
* Incident analysis
* Response support
* Security visibility

### Security Objective

The objective of EDR is to provide security teams with greater visibility and the ability to investigate potentially malicious endpoint activity.

---

# 6. Endpoint Security Operations

Endpoint security is an important component of a broader security-operations strategy.

EDR technologies can provide security analysts with endpoint information that can support investigations and incident-response activities.

### Security Operations Workflow

```text
Endpoint Event
      ↓
EDR Telemetry
      ↓
Detection
      ↓
Security Analysis
      ↓
Investigation
      ↓
Response
      ↓
Recovery
```

Integrating endpoint monitoring into security operations can improve visibility and support faster identification of potential threats.
