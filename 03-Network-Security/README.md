This section presents graduate-level work completed in **CS 09612 – Network Security**, combining academic coursework, hands-on network defense training, and a comprehensive graduate security project.

## Security Concepts

The work in this section demonstrates understanding of the relationship between **preventive, detective, and corrective security controls**.

```text
Identify Assets & Risks
        ↓
Design Security Controls
        ↓
Implement Preventive Controls
        ↓
Monitor & Detect Threats
        ↓
Respond to Security Events
        ↓
Recover Critical Services
        ↓
Evaluate & Improve
```

This approach connects technical network defense with broader security operations, governance, and organizational resilience.
