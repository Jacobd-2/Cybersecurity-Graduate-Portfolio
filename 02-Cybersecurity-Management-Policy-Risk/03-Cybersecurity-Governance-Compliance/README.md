## Project Overview

This project developed a comprehensive **Cybersecurity Program for Green Foods Market**, a locally owned fresh produce business with both in-store and online operations.

The project integrates cybersecurity governance, risk management, security policies, workforce security, physical security, asset management, technology controls, patch management, network security, website security, compliance considerations, and continuous improvement into a structured cybersecurity program.

The program was designed to establish a practical security foundation for a small organization with limited resources while addressing the organization's operational and cybersecurity risks.

---

# Project Objectives

The primary objectives of the cybersecurity program were to:

1. Establish a structured cybersecurity governance program.
2. Protect company, employee, and customer information.
3. Identify and manage cybersecurity risks.
4. Develop security policies and procedures.
5. Establish appropriate security controls.
6. Improve physical and technical security.
7. Strengthen workforce security and security awareness.
8. Improve vulnerability and patch management.
9. Protect network and website infrastructure.
10. Establish security monitoring and performance metrics.
11. Address applicable compliance considerations.
12. Establish a continuous improvement process.

# 16. Patch Management

The program establishes risk-based patch-management priorities.

| **Priority** | **Target Timeline** |
| ------------ | ------------------- |
| Emergency    | 24–48 hours         |
| High         | 1–2 weeks           |
| Medium       | 1 month             |
| Low          | 3–4 months          |

Patch management helps reduce exposure to known vulnerabilities and supports the organization's overall vulnerability-management strategy.

---

# 17. Network Security

The program addresses network security through layered controls.

Key recommendations include:

* Network segmentation
* Firewall protection
* Separate public and private wireless networks
* Secure administrative access
* Multi-factor authentication
* Endpoint protection
* Intrusion detection
* Regular network reviews
* Security assessments
* Screen-lock requirements
* Security awareness training

The project emphasizes defense in depth rather than relying on a single security control.
